Como hospedar no GitHub Pages

Este projeto foi construído em formato 100% estático (HTML, CSS e JS nativos), o que significa que ele funciona diretamente no GitHub Pages sem precisar instalar nada!

1
Envie o código para o GitHub

Crie um repositório no seu GitHub (ex: pet-carol) e faça o push dos arquivos:

git init
git add .
git commit -m "Meu Pet Mágico Seguidor ✨"
git branch -M main
git remote add origin https://github.com/SEU-USUARIO/pet-carol.git
git push -u origin main
2
Ative o GitHub Pages nas configurações

No seu repositório no GitHub:

  1. Clique na aba Settings (⚙️ Configurações).
  2. No menu esquerdo, clique em Pages.
  3. Em Build and deployment > Branch, escolha main e pasta / (root).
  4. Clique em Save!
3
Pronto! Compartilhe o link ✨

Em 1 ou 2 minutos, o GitHub vai gerar o link público da sua página:

https://SEU-USUARIO.github.io/pet-carol/

Qualquer pessoa ou a Carol poderá abrir no celular ou computador e o pet vai segui-la!
